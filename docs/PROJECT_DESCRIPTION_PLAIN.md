# DeadDrop: What It Is and How It Works

## The short version

DeadDrop is a pair of small, dedicated devices that let two specific people send private messages to each other. Nobody else can read those messages, not a company, not an app maker, not anyone who might intercept them along the way. Each device is a small computer with its own touchscreen, built specifically for this one purpose.

## How the messages stay private

When you send a message, it gets locked up before it ever leaves your device, using a method that only the other paired device can unlock. Think of it like a mailbox where only two people in the world have a working key, and the key was never sent through the mail itself, so nobody could have copied it along the way. Even if someone managed to intercept the message while it was traveling between the two devices, all they would see is scrambled, unreadable data.

The two devices also check each other's identity every single time they connect, using their own private set of credentials that only these two devices recognize. Neither device will talk to anything else, and nothing else can pretend to be one of them.

## What happens if a device is lost or stolen

Each device can be locked with a PIN, the same idea as a phone lock screen. If someone guesses wrong repeatedly, the device makes them wait longer between tries, and that waiting period is remembered even if the device gets restarted, so there is no easy way around it.

More importantly, everything stored on the device is scrambled in a way that is tied to that one specific physical device. If someone pulled the memory card out and tried to read it on a different computer, or even a second device just like it, they would find nothing but meaningless data. The information can only be unlocked by being inside the exact device it was set up on.

There is also a panic button, in a sense. Either device can trigger a command that instantly and permanently erases all message history on both devices at once, so if a device is ever in the wrong hands, whoever still has the paired device can wipe everything remotely, right away.

## How the two devices actually talk to each other

The devices do not need to be on the same WiFi network, or even in the same city. They connect to each other over a private network connection built for exactly this kind of pairing, which works over normal home or business internet without ever exposing the conversation to the open internet. If your device changes location, changes WiFi networks, or gets restarted, it will find its way back to its paired device automatically, without anyone needing to set anything up again.

## What this does and does not protect against

This system is genuinely good protection against most people who might try to snoop, intercept messages, or get into a lost or stolen device. It was built carefully, tested extensively, and checked against real attack attempts along the way.

It is honest to say it is not built to withstand a large, well funded organization or government dedicating serious time and money specifically to breaking into it. Very few things anyone builds, including much larger and better funded products, can honestly claim that. For everyday privacy between two people who want their conversation to stay just between them, it does exactly what it is meant to do.
